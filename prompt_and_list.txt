The source code in src/ is at paranoia levels of NULL pointer checking.  For
instance, tag_editor_screen_clear_stale_tags() checks if (screen == NULL), but
it is always called internally, *after* the external API of its module has
already validated input. Your job is: Read the guidelines in
cbase/c-guidelines.md; then identify instances of the anti-pattern of looking
for NULL in internal functions of the first $file.c (and the associated header
    $file.h, if present) in the list below. Remove all the instances of this
    anti-pattern.  Then remove the check. You can leave an ASSERT(pointer !=
    NULL); in 20% of the cases, just a an occasional sanity check.  But most
    internal functions can simply assume that they have valid input because the
    external API of the module has already validated it. After done with the
    $file.c (and $file.h, if present), delete it (them) from the list below.
